# NovaLoom Digital — বাংলা সংস্করণ

এই আপডেটে আগের Next.js + Prisma + PostgreSQL প্রজেক্টের কাঠামো ও API ধরে রেখে বাংলা-কেন্দ্রিক UI যুক্ত করা হয়েছে।

## কী পরিবর্তন হয়েছে
- ওয়েবসাইটের ডকুমেন্ট ভাষা বাংলা (`lang="bn"`) করা হয়েছে।
- হোমপেজ, নেভিগেশন, সার্ভিস তালিকা, সার্ভিসের বিস্তারিত এবং বুকিং/রিকোয়েস্ট ফর্ম বাংলায় সাজানো হয়েছে।
- সার্ভিসের নাম, বর্ণনা ও অন্তর্ভুক্ত কাজগুলো বাংলায় করা হয়েছে।
- কাস্টমার ড্যাশবোর্ডের শুরুতে জনপ্রিয় চারটি সার্ভিস কার্ড যোগ করা হয়েছে; সব সার্ভিস দেখার লিংকও আছে।
- ড্যাশবোর্ডে সার্ভিসের স্লাগের বদলে বাংলা নাম দেখানো হয় এবং বুকিং স্ট্যাটাসের বাংলা লেবেল যোগ করা হয়েছে।
- অ্যাডমিন ও লগইন/রেজিস্ট্রেশন স্ক্রিনের প্রধান UI-তে বাংলা কপি যোগ করা হয়েছে।
- আগের Teal Green ব্র্যান্ড কালার, অ্যানিমেশন ও responsive stylesheet ব্যবহার করা হয়েছে।
- বিদ্যমান API endpoint, authentication, Prisma schema এবং database model পরিবর্তন করা হয়নি।

## চালানোর নিয়ম
1. `.env` ফাইলে আগের মতো `DATABASE_URL`, Auth secret এবং প্রয়োজনীয় environment variables সেট করুন।
2. `npm install`
3. `npx prisma generate`
4. `npx prisma db push` (শুধু প্রয়োজন হলে এবং ডেটাবেস স্কিমা যাচাই করে)
5. `npm run db:seed` (প্রথমবার বা সার্ভিস ডেটা আপডেট করতে প্রয়োজন হলে)
6. `npm run dev`

## গুরুত্বপূর্ণ
এই আপডেটে সোর্স কোডের JSX/JavaScript syntax পরীক্ষা করা হয়েছে। তবে এখানে প্রকৃত Neon credentials ও environment variables ছাড়া পূর্ণ Next.js production build, database connection, authentication, payment এবং deployment পরীক্ষা করা হয়নি। ডিপ্লয় করার আগে নিজের `.env` দিয়ে `npm run build` চালিয়ে পরীক্ষা করুন।
